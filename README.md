# 低模质量检查 (Lowpoly Check)

Blender 低多边形模型质量检查与优化工具插件。

## 目标

为低多边形（low-poly）美术资产提供一套开箱即用的质量检查工具，
把「靠肉眼逐个模型检查」变成「一键扫描 + 定位问题元素」。

## 功能规划

计划覆盖四个维度：

1. **网格拓扑** —— N-gon 面、重叠面、错误法线、非流形边、孤立几何体
2. **顶点质量** —— 未焊接点、共线顶点、密集顶点
3. **面质量** —— 退化几何体、非平面四边面、内凹四边面
4. **场景优化** —— 高面数物体、小倒角结构、朝下水平面、穿插物体、非均匀缩放

## 环境要求

- Blender 3.4.0 及以上
