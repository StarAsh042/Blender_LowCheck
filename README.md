## 功能特性

插件把低模质检按**模型制作流程**分成 4 组，共 **16 项**检测。

### 1. 网格拓扑

| 检测项 | 说明 | 结果显示 |
| --- | --- | --- |
| N-gon 面检查 | 多于 4 条边的面 | 面 |
| 重叠面检查 | 顶点位置完全重合的面 | 面 |
| 错误法线检查 | 绕序翻转 / 整体朝内的面 | 面 |
| 非流形边检查 | 被 3 个及以上面共用的边 | 边 |
| 孤立几何体检查 | 不属于任何面的悬浮顶点与悬浮边 | 顶点 |

### 2. 顶点质量

| 检测项 | 说明 | 参数 |
| --- | --- | --- |
| 未焊接点检查 | 位置重合但未被边连接的顶点 | 未焊接阈值 |
| 共线顶点检查 | 三点共线形成的废点 | 共线阈值 |
| 密集顶点检测 | 局部顶点密度过高 | 密集距离/数量阈值 |

### 3. 面质量

| 检测项 | 说明 | 参数 |
| --- | --- | --- |
| 退化几何体检查 | 零长度边 + 零面积面 | 退化边/退化面阈值 |
| 非平面四边面检查 | 四个顶点不共面的四边面 | 非平面阈值 |
| 内凹四边面检查 | 存在大于 180° 内角的四边面 | — |

### 4. 场景优化

| 检测项 | 说明 | 参数 |
| --- | --- | --- |
| 高面数物体检测 | 面数超过阈值的物体 | 面数阈值 |
| 小倒角结构检测 | 宽度过小的倒角面 | 倒角宽度阈值 |
| 朝下水平面检测 | 法线朝下的水平面（可能浪费面数） | 面积/角度阈值 |
| 穿插物体检测 | 包围盒互相重叠的物体 | 重叠比例阈值 |
| 非均匀缩放物体检测 | 缩放值不统一的物体 | — |

### 全局功能

- **运行全部检查**：一键执行全部 16 项检测，带进度条，单项失败不影响其余项。
- **检测范围**：可切换「仅处理选中物体」，在大场景中只检查关注的部分。
- **结果汇总**：面板顶部显示问题总数。
- **一键选择**：每项检测都可以把问题元素选中（Blender 2.8+ 多物体同时编辑，
  所有问题物体一次性进入编辑模式）。
- **清除结果**：清空所有检测结果与计数，不修改模型。
- **参数重置**：每个阈值单独重置，或一键重置全部参数。

## 安装方法

### 方式一：安装 ZIP（推荐）

1. 运行打包脚本生成 ZIP（ZIP 已随交付物提供）：

   ```bash
   # 使用 Blender 自带的 Python（无需额外安装 Python）
   "<Blender 可执行文件>" --background --python tools/build_addon.py
   # 产物: dist/Blender_LowCheck-v1.0.0.zip
   ```

2. 打开 Blender，进入 `编辑 > 首选项 > 插件`（`Edit > Preferences > Add-ons`）。
3. 点击右上角 `安装...`（`Install...`），选择 `Blender_LowCheck-v1.0.0.zip`。
4. 在插件列表中找到 **`低模质量检查 (Lowpoly Check)`**，勾选左侧复选框启用。

### 方式二：复制文件夹

1. 把整个 `Blender_LowCheck` 文件夹复制到 Blender 的用户插件目录：

   | 平台 | 路径 |
   | --- | --- |
   | Windows | `%APPDATA%\Blender Foundation\Blender\3.4\scripts\addons\` |
   | macOS | `~/Library/Application Support/Blender/3.4/scripts/addons/` |
   | Linux | `~/.config/blender/3.4/scripts/addons/` |

2. 重启 Blender，在 `编辑 > 首选项 > 插件` 中勾选启用。

### 方式三：自定义脚本目录（不污染 Blender 安装目录）

设置环境变量后启动 Blender，插件文件夹放在
`<自定义目录>\addons\Blender_LowCheck`：

```powershell
$env:BLENDER_USER_SCRIPTS = "D:\blender_scripts"
```

### 验证安装

安装成功后：

- 3D 视图按 `N` 打开侧边栏，出现 **`Lowpoly Tools`** 标签页；
- 控制台执行 `bpy.ops.lowpoly.run_all_checks()` 可用；
- 卸载（取消勾选）后再次启用，插件仍能正常工作。

## 使用方法

### 基本流程

1. 在 3D 视图中按 `N` 打开侧边栏，切换到 `Lowpoly Tools` 标签页。
2. （可选）勾选「仅处理选中物体」，或直接对全部可见网格生效。
3. 点击 **运行全部检查**，或逐项点击某项检测的 `检查` 按钮。
4. 查看每项右侧的数量；点击 `选择` 按钮即可在编辑模式下高亮问题元素。
5. 处理完问题后再次检测，或点击 **清除结果** 重置计数。

> **提示**：检测只读取网格数据，不会修改模型，可放心使用。

### 单项检测

每个检测框内的按钮含义：

| 按钮 | 作用 |
| --- | --- |
| `检查` | 仅运行该项检测并更新数量 |
| `选择` | 选中该项最近一次检测出的问题元素（需先运行检测） |
| `⟲`（参数右侧） | 把该阈值恢复为默认值 |

## 参数说明

悬浮在参数或重置按钮上可看到默认值提示。

### 面质量

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 非平面阈值 | `0.01` | 四边面顶点偏离拟合平面的最大距离，超过则判为扭曲四边面 |
| 退化边阈值 | `0.0001` | 边长小于该值判为零长度边 |
| 退化面阈值 | `0.0001` | 面积小于该值判为零面积面 |

### 顶点质量

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 共线阈值 | `0.01`（弧度） | 允许顶点偏离直线的最大角度；越小越严格 |
| 未焊接阈值 | `0.001` | 两点距离小于该值且无边相连即判为未焊接 |
| 密集距离阈值 | `0.1` | 顶点密度搜索半径 |
| 密集数量阈值 | `5` | 半径内顶点数达到该值即判为密集 |

### 场景优化

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 面数阈值 | `50` | 物体面数超过该值判为高面数物体 |
| 倒角宽度阈值 | `0.1` | 四边面最短边小于该值且相邻面 ≥ 2 个，判为小倒角 |
| 朝下面积阈值 | `0.0` | 检测朝下面的最小面积，`0` 表示全部检测 |
| 朝下角度阈值 | `5.0`（度） | 面法线与竖直向下方向的夹角小于该值视为朝下水平面 |
| 穿插重叠阈值 | `0.0` | 包围盒重叠比例阈值（0–1），`0` 表示只要有接触就算穿插 |

### 新增一个检测项需要改哪里？

得益于 `registry.py`，通常只需 **1~2 处**：

1. 在 `properties.py` 里加计数属性（以 `_count` 结尾）和阈值参数（以 `_threshold` 结尾）；
2. 在 `registry.py` 的 `CHECKS` 中登记一行，并在 `operators/check_operators.py`
   或 `operators/optimize_operators.py` 中补上检测函数与两个操作符类
   （函数映射表 `_CHECK_FUNCTIONS` / `_OPTIMIZE_FUNCTIONS` 各加一项）。

面板分组、按钮、数量文案、汇总计数、批处理顺序都会自动跟随。
测试 `test_03b_panel_references_are_valid` 会校验三者一致性，漏改会被立刻发现。

## 技术说明

### 架构：Python 薄壳 + Rust 内核

Blender 侧的注册、面板与操作符全部由 Python 负责；**几何计算**中风险最高、
耗时最长的「顶点质量算法组」下沉到 Rust 内核（`src/lib.rs`），通过 PyO3 以
**abi3-py38（CPython 稳定 ABI）** 暴露给 Python。

- **性能**：顶点质量检测从 O(n²) 的两两比较改为 Rust 侧的空间网格邻域查询，
  大网格下不再卡住 Blender 主线程。
- **可测试性**：内核可以脱离 Blender 独立测试（`cargo test`），
  `tests/test_rust_parity.py` 还会逐点比对 Rust 与纯 Python 两条实现，
  保证「Rust 只允许更快，不允许不同」。
- **可回退**：内核扩展缺失或调用失败时，`utils.py` 会自动回退到纯 Python
  实现，插件仍可正常安装与使用。

构建内核：

```bash
python tools/build_rust.py      # 等价于 cargo build --release + 复制为扩展模块
```

> ⚠️ Windows 上 abi3 扩展依赖 `python3.dll`（稳定 ABI 转发层），它位于
> Blender 安装根目录。在 Blender 进程内加载正常；若要在独立 Python 里测试，
> 需要把 Blender 根目录加入 `PATH`。

### 检测算法

1. **扭曲四边面**：取三点构造平面法线（前三点共线时自动回退到另一组三点），
   计算四顶点到该平面的最大距离。
2. **内凹四边面**：用叉积符号法判断。叉积会先归一化，因此判据与模型尺度无关；
   相邻两条边的叉积方向出现符号反转即说明存在大于 180° 的内角。退化角会先行排除。
3. **错误法线**：
   - **绕序一致性**：流形网格中同一条边必须被其两个面沿相反方向遍历。
     以面为单位做 BFS，可把一个连通分量分成「与起点一致 / 与起点相反」
     两组，后者即被翻转的面。该判据纯拓扑，不会像法线投票那样在
     对称结构上互相抵消。
   - **整体朝向**：若连通分量闭合（每条边恰好 2 个面），用散度定理计算
     有向体积；体积为负说明整体朝内，此时报告多数派那一组。
   - 非流形边上的绕序没有明确定义，会被主动跳过以避免误报。
4. **未焊接点**：KDTree 半径查询，找出距离小于阈值且无边相连的顶点对。
5. **共线顶点**：度数恰为 2 的内部顶点，若两条单位边向量的
   `|cos θ| >= cos(阈值)` 即判为共线（阈值是**允许偏离直线的最大弧度**）。
6. **密集顶点**：KDTree 半径查询统计邻域顶点数量。
7. **重叠面**：用 KDTree + 并查集把顶点聚成「位置簇」，以「面的顶点簇编号集合」
   为键；键相同的面即位置重合。相比坐标量化分桶，不存在相邻网格边界漏检。
8. **穿插物体**：世界空间 AABB 相交检测 + 重叠体积比，并按最小 x 排序做扫描剪枝。

### 性能与健壮性

- **BMesh 批量会话**（`utils.detection_session()`）
  一次「运行全部检查」中，每个物体的 BMesh 只构建一次，被全部 16 项检测
  复用；会话结束统一释放（异常安全）。会话带内存预算
  （最多缓存 200 万顶点 / 单物体 25 万顶点），超出后自动退化为一次性构建。
  会话同时缓存「本次检测的目标物体列表」，避免每项检测重复遍历场景。
  缓存命中时会用 `is` 校验对象身份，防止「对象被删除后名字复用」导致的错配。
- **穿插检测的宽相位剪枝**
  每个物体的世界空间 AABB 只计算一次（O(n)），再按最小 x 排序扫描，
  x 轴不可能重叠即可提前终止内层循环；结果按场景顺序去重，**顺序确定可复现**。
- **选择不走 BMesh 往返**
  直接写入 `mesh.vertices/edges/polygons` 的 `select` 标志，避免
  `bm.to_mesh()` 重建网格数据；配合 Blender 2.8+ 的多物体编辑能力，
  所有问题物体一次性进入编辑模式。
- **统一异常守卫**
  37 个操作符在注册时自动包装 `execute`，任何未预期异常都会被捕获、
  打印堆栈并返回 `CANCELLED`，不会让 Blender 处于不一致状态。
  守卫的安装是幂等的，注销时会**还原**（而非删除）原始 `execute`。
- **失效引用防护**
  检测结果长期持有物体引用；所有读取路径都会先校验物体是否已被删除
  （`utils.is_object_alive`），避免 `ReferenceError` 崩溃。
- **后台模式可用**
  `blender --background` 下没有窗口上下文，插件会自动跳过进入编辑模式、
  进度条等 UI 操作，检测逻辑照常执行（便于 CI / 批处理）。
- **幂等注册/注销**
  插件的 `register()` / `unregister()` 可安全重复调用；注册失败会自动回滚
  已注册的部分，不会残留半注册状态。
- **开发热重载**
  `reload_modules()` 按「先注销 → 再 reload → 再注册」执行，不会留下
  「已注册但模块中已无引用」的孤儿类。

## 已知局限

请在使用前了解以下边界，避免把「建议」当成「结论」：

1. **穿插物体检测基于世界空间包围盒（AABB），是保守判据。**
   它只能说明「两个物体**可能**穿插」，不能证明实际网格相交——分离但包围盒
   重叠的物体会被报出。可用「穿插重叠阈值」过滤掉浅重叠（仅边界相切）的情况。
2. **小倒角检测不校验夹角。** 判据是「四边面最短边 < 阈值且相邻面 ≥ 2 个」，
   因此细长面、薄片结构也可能被报出。
3. **朝下水平面检测只看朝向。** 仅依据面法线与竖直向下的夹角，不判断该面
   是否可见、是否真的浪费面数。
4. **错误法线检测依赖拓扑绕序。** 非流形边上的绕序没有明确定义，会被主动
   跳过（这类边由「非流形边检查」单独负责）。
5. **退化几何体的选择以边为主。** 同一模型同时存在退化边与退化面时，
   `选择` 只会选中退化边（退化边可定位其所属退化面）。
6. **孤立几何体的 `选择` 写的是顶点选择标志。** 悬浮边的两个端点本身就是
   悬浮顶点，因此端点会被一并选中。
7. **面板只显示数量，不提供逐物体结果列表。** 需要定位到具体物体时请使用
   各项的 `选择` 按钮。
8. **界面文案为硬编码中文**，未做多语言（i18n）支持。
9. **大场景开销随顶点数增长。** 未焊接点/密集顶点检测需为每个物体构建
   KDTree；顶点数超过 50 万时插件会给出提示，建议配合「仅处理选中物体」
   分批检查。
10. **「退化」判定使用绝对长度阈值。** 零长度边、零面积面，以及内凹判定中的
    退化边保护，都使用**绝对**阈值（默认 `0.0001`）。因此毫米级微缩资产可能
    被整体视为退化而跳过检测。内凹判定本身已做到尺度无关，但边长小于该绝对
    阈值的面会按「退化面」处理——此时请调小退化边/退化面阈值后重试。

## 常见问题与故障排除

### 插件无法加载

**症状**：`编辑 > 首选项 > 插件` 中可以勾选，但侧边栏没有 `Lowpoly Tools`。

**处理**：

1. 确认 Blender 版本 ≥ 3.4（`帮助 > 关于 Blender`）。
2. 打开 `窗口 > 切换系统控制台` 查看报错堆栈。
3. 确认插件目录结构完整（`__init__.py`、`registry.py`、`utils.py`、
   `properties.py`、`ui.py`、`operators/` 均在）。
4. 若手动改过代码，先取消勾选再重新勾选；必要时重启 Blender。

### 检测结果数量为 0

1. 确认场景中有可见的网格物体（`MESH` 类型，且未被隐藏）。
2. 若勾选了「仅处理选中物体」，确认已选中目标物体。
3. 阈值过严时会漏检，可适当放宽后重试。
4. 注意：未发现的检测项会**清空**该项的历史结果，数量为 0 表示
   本次确实没检出问题。

### 「选择」按钮无反应 / 提示"请先运行对应的检测"

- 需要先运行检测再点选择。
- 若运行检测后删除了相关物体，会提示"所在物体已被删除，请重新检测"，
  重新运行检测即可。

### 处理大型模型时卡顿

1. 使用「仅处理选中物体」分批检测。
2. 隐藏不需要检查的物体（隐藏物体不参与检测）。
3. 顶点数超过 50 万时会给出提示；此时建议分批处理。
4. 检测是只读操作，可随时按 `Esc` 中断（进度条会结束）。
